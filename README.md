# Сайт ЭРАGAMERU

Адрес: https://eragameru.github.io/

Исходники лежат в проекте игры, в папке `Site/`. Сюда их выкладывает Claude.

- `data/seller.js` — данные продавца (ФИО, статус, ИНН, почта). Подставляются на все страницы.
- `data/games.js` — каталог игр, ссылки на скачивание, платные наборы и цены.
- `games/<игра>/` — страница игры и её картинки.
- `assets/` — оформление (`site.css`) и логика страниц (`site.js`).
